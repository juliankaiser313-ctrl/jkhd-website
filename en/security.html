// Security

There are no client files here.

We sell nothing and work for no one. What has to be secured is that no program and no slip of the hand moves money nobody meant to move. Scroll.

01 · Kill switch

The kill switch shuts the door, not the window.

Once pulled, no new entries come about; open trades run out. It opens again only when a person acknowledges it with a note — and that survives every restart.

02 · The setting

Nothing goes beyond the machine's own setting.

An intervention can make the machine more careful, never bolder. A value past the setting is quietly pulled back; what you tightened yourself you may take back.

03 · Unclear

Unable to read means not acting.

What the system cannot read unambiguously does not count as permission. If the instruction stays unclear, trading starts with new entries blocked.

04 · Real money

“Real money” is a finding, not a claim.

No file can assert live operation. Instead it is checked: stand-ins, test doubles, copy templates and replayed recordings are recognised and refused.

05 · Manual trades

There is no path for manual trades.

Nobody can place an order by hand into the systematic accounts, we cannot either. Otherwise machine and hand could no longer be told apart, and the system could no longer be tested.

06 · The change

The change is a sequence, not a switch.

Block new entries, prove nothing is open, end the running process, witness the standstill, only then start the target state. Any ambiguity halts it and says why.

07 · Two limits

Two limits above everything, and none may be missing.

The sum of all open stop risks against an upper limit, and a loss brake across everything. If one of these limits is missing, nothing starts.

Records

What happened cannot be quietly altered.

Every entry carries a checksum over its predecessor; writing only appends. Change a line and you break the chain, and the break is reported.

Data

What is stored here at all: very little.

This website keeps no profile of you: no cookies, no trackers. Stored is only what you send yourself — an enquiry, a nickname on the leaderboard. The partner access keeps what a partner has given, otherwise only checksums and sign-ins that expire by themselves. There is no payment data.

Honestly

What we cannot show you.

No certification, no external audit, no cover around the clock, no redundancy. And no lock has ever held real money: no counterparty is attached.
